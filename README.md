# AI Research Center website

This repository serves the interactive website of **AI Research Center**, shown at
[airesearchcenter.com](https://airesearchcenter.com) and published here with GitHub Pages
([minh-doan.github.io/airesearchcenter-site](https://minh-doan.github.io/airesearchcenter-site/)).

It is a finished, static website, not research code. It holds only what a browser downloads
to display the site: the pages, stylesheet, minified scripts, fonts, images and the compact 3D
anatomy data. No analysis pipelines, study data, models or source code for the research live
here, and the repository is not meant to be cloned, built or reused.

| Path | What it is |
|---|---|
| `index.html` | the full page |
| `embed/` | chrome-free widgets for embedding: anatomy, zoom from body to molecule, facility |
| `css/`, `js/`, `fonts/`, `img/`, `data/` | styles, bundled scripts, typefaces, images, 3D and chart data |
| `.github/workflows/pages.yml` | publishes this folder to GitHub Pages on every push |

The feature values in the charts are demonstration data, and the illustrations are described
in the site's footer.
